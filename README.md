# GraduationCermoney

A comprehensive TypeScript-based application for managing graduation ceremony events, including planning, scheduling, and coordination.

## 📋 Overview

GraduationCermoney provides tools and utilities to organize and manage all aspects of graduation ceremonies—from event planning and guest management to logistics coordination and scheduling.

## ✨ Features

- **Event Planning** — Create and manage graduation ceremony events
- **Scheduling** — Organize timeline and schedule for ceremony activities
- **Configuration Management** — Centralized app configuration and environment setup
- **Express Backend** — Built with Express.js and TypeScript for robust API endpoints
- **Modular Architecture** — Well-organized project structure with clear separation of concerns

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v16 or higher recommended)
- **npm** or **yarn** package manager
- **TypeScript** support

### Installation

```bash
# Clone the repository
git clone https://github.com/zaynabhousseini2004-glitch/GraduationCermoney.git

# Navigate to the project directory
cd GraduationCermoney

# Install dependencies
npm install
```

### Build & Run

```bash
# Build the TypeScript project
npm run build

# Start the application
npm start

# Development mode with hot reload (if available)
npm run dev
```
